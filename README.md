
# TalentLMS Front-End Bundle

## How to Use
1. Upload `index.html` and `script.js` to a public web server or embed directly in TalentLMS using an iframe.
2. Update the `fetch` URL in `script.js` to point to your Render backend endpoint.
3. In TalentLMS, create a new unit and select **Iframe** option. Paste the URL of your hosted `index.html`.

## Requirements
- Backend must be deployed and accessible via HTTPS.
- Environment variables set in Render for API keys.
